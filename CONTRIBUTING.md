# Contributing

Thanks for wanting to help!

- Bugs and ideas: open an issue (the form asks for your version, computer and browser).
- Code: fork, make your change, run `python3 -m unittest discover -s tests -v`, open a pull request.
- Keep it beginner-friendly: plain words in the UI, no SPICE jargon on the main screen.
- Keep it light: standard-library Python only, no JavaScript libraries, must run on a 7th-gen Core i3.
